# structrank — 稀疏矩阵结构秩与块三角化

仅依据稀疏矩阵的**非零位置**（0/1 模式，不看数值、不做数值消元）计算：

1. **结构秩**：行列二部图的最大匹配基数；
2. **Dulmage–Mendelsohn 三区**：以未匹配行/列为起点沿交替路识别欠定区、
   良定区、过定区；
3. **良定区块三角化**：在匹配有向图上求强连通分量（SCC），得到不可约
   对角块的拓扑序与全局行列置换；
4. **匹配证书**：匹配数组 + König 最小顶点覆盖，可独立复核最优性。

纯 Python 标准库实现，核心算法全部手写（Kuhn 增广路、交替路 BFS、
Kosaraju SCC、Kahn 拓扑排序、König 覆盖），不调用任何第三方同类实现。

## 运行环境

- Python **3.14.7**（仅使用 3.14 标准库；3.10+ 亦可运行，未在其他版本验证）
- Linux 原生运行，**无需安装任何第三方依赖**，无需网络/账号/Docker/数据库
- 输入上限：行数、列数均为 **0 ≤ n ≤ 100**

## 公开接口

```python
import structrank as sr

result = sr.analyze(nonzeros, n_rows=None, n_cols=None, *, max_steps=None)
result.structural_rank          # int：最大匹配基数
result.match_row                # tuple：行 -> 配对列（-1 未匹配）
result.match_col                # tuple：列 -> 配对行（-1 未匹配）
result.regions                  # Regions：under/well/over 各自行列集合
result.btf.blocks               # 不可约块（拓扑序），每块含原下标与新位置
result.row_perm/result.col_perm # 新位置 -> 原下标的全局置换
result.block_bounds             # 每块 (行起,行止,列起,列止) 半开区间

sr.structural_rank(nz, n_rows, n_cols)          # 仅取结构秩
sr.verify_certificate(nz, match_row, match_col, # König 覆盖独立复核
                      n_rows, n_cols)
```

**输入形式**（重复非零位置自动去重）：

- 坐标对集合：`{(0, 0), (0, 2), (1, 1)}`，配合 `n_rows/n_cols`（可省略，
  省略时由最大下标 +1 推断，空集合推断为 0×0）；
- 行序列：`[[0, 2], [1], []]`（每行是列下标可迭代对象，此时不可再传
  `n_rows`，行数由外层长度决定）。

`StructuralAnalysis`、`Regions`、`Block`、`BlockTriangularForm`、
`VerifyReport` 均为冻结 dataclass，可比较、可复现；同输入同结果，
不依赖任何全局状态。

## 错误语义（先固定的契约）

- 所有异常继承 `StructuralRankError`。
- **非法输入确定性拒绝**：`InvalidStructureError`（`ValueError` 子类）。
  维度越界（>100 或负数）、下标越界、下标非整数、`None`/字符串/畸形对，
  错误信息带可定位位置（如 `nonzeros 第 1 项 的列下标 ... 收到 nan`）。
  除“重复位置去重”外不做任何静默纠正。
- **数值取值**：浮点下标拒绝 `NaN`/`±Infinity`；`2.0` 这样的整值浮点接受
  为下标 2，`2.5` 拒绝。
- **bool 拒绝**：`bool` 是 `int` 子类，维度、下标、`max_steps` 收到
  `True/False` 一律拒绝。
- **搜索预算与证明无解严格分开**：`max_steps` 限制增广路检查的边数；
  耗尽且未证明最优时抛 `SearchBudgetExhaustedError`（`RuntimeError` 子类，
  **不是** `ValueError`），携带预算、已用步数与部分匹配仅供诊断。二部图
  恒存在匹配，库内不存在“证明无解”；拒绝只针对非法输入。默认
  `max_steps=None` 不限预算。
- 库是无状态纯函数：预算耗尽只抛异常，不产生任何部分结果或外部变更。

## 设计取舍

- **结构判断 ≠ 数值消元**：结构秩是“对几乎所有数值赋值成立的秩”，由最大
  匹配给出；本库不读矩阵元数值，不做高斯消元/LU。
- **DM 三区方向**：从所有未匹配行沿交替路（非匹配边先行）可达者为过定区；
  从所有未匹配列沿反向交替路可达者为欠定区；其余为良定区。最大匹配保证
  两可达集不交。分区与具体选哪个最大匹配无关（测试枚举全部最大匹配
  验证这一点）。
- **块三角化只在良定区做**：在“行有向图”上建边——对每条非零元 `(r,c)`，
  沿列 c 的匹配边连有向边 `r → match_col[c]`；其 SCC 即不可约块，
  SCC 收缩图按 Kahn 拓扑序排列。置换后块间非零元只出现在块对角线上方
  （严格块上三角）。欠定/过定条带作为整体排在良定区之上/之下。
- **置换语义**：`perm[i] = 原下标`（新位置 → 原下标），与常见数值库的
  行/列置换数组一致。条带内匹配边排在条带左上、未匹配顶点排在末尾。
- **确定性**：行按升序增广、邻接表排序、拓扑平局按块内最小下标打破，
  同一输入永远得到同一置换（SCC/块划分本身是唯一的，块内顺序也是确定的）。
- **证书独立可验**：`verify_certificate` 用 König 构造（不可达行 ∪ 可达列）
  复算最小顶点覆盖并逐边检查，不依赖求解路径；测试中的期望值则来自
  `tests/reference.py` 的全枚举与独立 Tarjan 实现，**不调用被测核心**
  生成期望值，往返一致仅作补充检查。

## 浮点与误差口径

本库输出全部是整数组合量（秩、下标、置换、块编号），**没有浮点结果，
不存在数值误差/容差**。唯一与浮点相关的行为是输入校验：整值浮点
（如 `3.0`）按下标 3 接受，非有限值与非整值一律拒绝。结构结论是
组合意义上的精确结论，不使用任何容差。

## 测试概览

- 枚举 0..4 阶（含矩形）大量随机 0/1 模式，结构秩与朴素全枚举逐一比对；
- 空矩阵 0×0、空行/空列、纯欠定矩形、纯过定矩形、三区共存、矩形不连通
  时方形成分落入良定区的对照例；
- 枚举全部最大匹配验证 DM 分区唯一性（“多个匹配但同结构区”）；
- 不可约块：全满 2×2 为单 SCC；`[1 1;1 0]` 这类可约模式必须拆成两个
  1×1 块（防误报不可约）；上/下三角块序方向；随机图块划分对独立
  Tarjan SCC；
- 置换后结构独立检查（双射、区域块形、严格块上三角、块边界一致、
  匹配对对齐）；
- 证书：接受最大匹配、拒绝非最大匹配、拒绝非非零边、拒绝双向映射矛盾；
- 输入：bool、NaN/Infinity、越界、畸形对、行序列形式、维度推断；
- 预算：耗尽异常类型与拒绝区分、预算充足完成、非正预算拒绝；
- 接口边界 100×100（稀疏环单 SCC、稠密全满单块）与 101 拒绝。

## 已知限制 / 不宣称的内容

- 只实现本题契约的数学子集：无权二部匹配、DM 粗分解与良定区粗粒度
  块三角化；不提供细分解（fine DM decomposition）、带权匹配、数值秩、
  符号分析或矩阵文件格式读写，**不宣称兼容 Harwell-Boeing/Matrix Market
  等行业标准**。
- 上限固定 100×100；超限直接拒绝。算法为 Kuhn O(VE)，对上限规模足够；
  未针对百万级矩阵工程优化。
- 输入须可一次性物化为集合（不支持流式/超大数据源）。
- 非零位置只有“有/无”两态，不区分候选主元强弱等数值属性。
